NEBAN INTERNATIONAL SCHOOLS WEBSITE
====================================

This is a complete static, responsive website.

Files:
- index.html
- css/styles.css
- js/script.js
- assets/school-flyer.jpg
- assets/admissions-flyer-top.jpg
- assets/secondary-section.jpg
- assets/school-features.jpg

DEPLOYMENT
1. Upload all files and folders exactly as they are to GitHub.
2. Deploy the repository on Vercel, Netlify, or GitHub Pages.
3. No build command is required. The project is plain HTML/CSS/JavaScript.

FUNCTIONAL FEATURES
- Responsive mobile navigation
- Smooth section navigation
- Admission enquiry form that opens WhatsApp
- Click-to-call phone numbers
- Floating WhatsApp button
- Gallery lightbox
- Automatic copyright year
- No database or server required
